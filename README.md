## How it works

Given a simple text prompt, the system transforms it into a multi-shot visual narrative.

It first generates a high-level storyboard, then breaks it down into individual shots. Each shot is expanded with detailed prompt engineering, including camera movement, lighting, and scene context.

These prompts are sent to a video generation model (Seedance), which produces short cinematic clips with consistent visual style.

Overall, the system simulates a simplified film production pipeline using AI.
